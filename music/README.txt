FLOW SONG - put your own music here!

Save your song in this folder with ONE of these names:

    flow-song.mp3      (best choice)
    flow-song.ogg
    flow-song.wav
    flow-song.m4a

When the player finds the Flow Song creature in the Windy Highlands, this file plays
(it loops) whenever they switch "Flow Song" on in the Pause menu.

If no file is here, the game plays a little built-in tune instead, so nothing breaks.

Tip: the folder has to sit NEXT TO glitching-tales-OFFLINE.html (and index.html).
